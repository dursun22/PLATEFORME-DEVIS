🔥 Connecter Firebase

Première configuration. À faire une seule fois.
Avant de continuer, créez un projet Firebase :
  1. Allez sur console.firebase.google.com (connectez-vous Google)
  2. Cliquez « Ajouter un projet », nommez-le mes-devis, désactivez Analytics
  3. Une fois créé : menu gauche → Authentication → Commencer → Sign-in method → activez E-mail/Mot de passe
  4. Menu gauche → Firestore Database → Créer une base → mode production → emplacement eur3
  5. Engrenage ⚙️ → Paramètres du projet → onglet Général → faites défiler → cliquez l'icône </> pour ajouter une web app → nom : mes-devis-web → Enregistrer
  6. Copiez tout l'objet const firebaseConfig = { ... } qu'il vous montre

🔒 Règles de sécurité Firestore

Une dernière étape : autoriser uniquement les utilisateurs connectés à lire/écrire vos données.
  1. Retournez sur la console Firebase
  2. Menu gauche → Firestore Database
  3. Onglet Règles en haut
  4. Remplacez tout le contenu par le bloc ci-dessous
  5. Cliquez Publier
